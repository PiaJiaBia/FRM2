# Triage Labels

技能中的五个标准分诊角色映射到以下 GitHub 标签。应用角色时使用对应标签字符串。

| 标准角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待评估 |
| `needs-info` | `needs-info` | 待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格明确，可由代理实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不予实施 |
