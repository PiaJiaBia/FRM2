# 市场风险计算工作台：第1章完整接入与18章扩展框架

状态：用户已调用 implement-spec 开始实施。规格 Issue：https://github.com/PiaJiaBia/FRM2/issues/1。

## Problem Statement

用户已用 Python 计算器和 notebook 复现市场风险教材18章，并建立 DataFrame 数据层、MySQL 存储和 controller 编排。当前操作依赖 Python 与 notebook，缺少可视化的数据准备、模型配置、结果比较及历史记录入口。用户希望兼顾教材学习和真实数据分析，同时保留纯计算器、通用类组合及显式数据准备的设计理念。

## Solution

构建个人本机使用的中文桌面浏览器工作台，技术栈为 React、TypeScript、Ant Design、Vite、ECharts。通过 Python HTTP 接口复用现有计算服务和远端 MySQL。首版交付数据集管理、计算记录和第1章完整工作流，其余17章展示目录并标记未接入。

主流程：选择教材示例或数据集 → 确认字段及口径 → 显式准备数据 → 配置模型 → 试算 → 查看数值、表格、图表与教材说明 → 手动保存或导出。

## Implementation Decisions

- 前端使用用户指定的五项技术；中文界面保留英文术语，优先电脑屏幕。左侧入口为数据集、章节计算、计算记录；主区配置在上、结果与图表在下，教材说明可折叠。
- 第1章提供数据准备、VaR、ES/谱风险、估计误差四个工作区；数据诊断作为相关工作区的辅助能力。其余章节只展示现有章节信息与未接入状态。
- 新增 Python HTTP 边界，默认仅本机访问、无账号体系。浏览器不直连MySQL，凭据不进入前端、导出文件或响应。具体HTTP框架由实施时选择，未将某个框架视为既定需求。
- 保留 service 的纯计算职责、DataFrame输入和通用参数/类组合风格。数据解析、适用性校验、排序、缺失处理、单位及符号转换留在调用边界。金融公式不在React中重复实现。
- 扩展现有controller与repository，复用函数调用、类组合、快照、事务和计算记录能力。新增明确的网页操作注册表，描述参数、字段角色、单位、说明及图表，不提供任意Python函数调用或代码执行入口。
- 接口覆盖章节与操作目录、示例预设、上传预览与确认、数据集列表/详情/准备/保存/命名/归档、试算任务提交/查询/取消、计算结果保存、记录列表/详情/命名/归档及导出。请求使用数据集版本ID、操作ID、显式参数和准备配置，响应提供稳定的任务、表格、指标与图表数据结构。
- 将Python持久化格式与浏览器响应格式分开。缺失和非有限结果保留其语义并清楚显示，不静默转为零或非法JSON。错误响应定位到可修正的字段或步骤，不泄露凭据。
- CSV/Excel上传先预览、配置字段及口径再保存。教材示例区分教材给定参数与可复现的演示样本，不将随机演示数据冒充教材原始样本。
- 准备步骤显式记录；结果保存为新数据集，记录来源版本和转换步骤。收益率首行缺失等自然结果先保留，由用户明确决定后续处理。
- 原始样本内容不可变；命名和归档作为管理元数据处理。扩展存储以支持字段口径、数据血缘、记录名称、归档状态、完整图表结果及查询分页；兼容已有快照和计算记录，不破坏旧数据。
- 历史损失与盈利输入在适配层明确区分符号。对数正态模型接收对数收益率并输出普通损失比例。参数法统一按收益率计算，首版不加入头寸金额换算。
- 模型比较要求相同样本来源、期间、频率、有效观测集合、结果单位和风险置信水平；算术/对数收益率按模型使用相应派生字段，不把两者混作同一种数据。
- ES/谱风险复用现有分位数与权重抽象，提供历史、正态、对数正态模型以及ES、指数权重的有效组合。图表曲线与收敛表由Python调用现有服务生成。
- 估计误差支持现有分位数、谱风险和Bootstrap能力。风险置信水平与区间置信水平独立。首版Bootstrap仅展示已有汇总统计和区间，不新增重采样分布图。
- 试算由按钮触发，不自动保存正式计算记录。手动保存时冻结输入版本、模型、参数、准备步骤、结果、图表所需数据及计算实现版本信息；重新打开显示保存结果，重算或改参数另存新记录。
- 耗时计算后台执行，状态包含等待、运行、完成、失败和已取消；仅有可测进度时显示百分比。页面切换不丢任务，取消须停止后续计算或阻止结果发布；取消或失败任务不能被当作成功结果保存。程序重启后不续算。
- 导出CSV表格、PNG图表和JSON配置；归档代替直接删除，被引用数据集始终可供历史记录追溯。

## Testing Decisions

- 测试边界：以浏览器可见的完整工作流为主要验收边界，通过真实HTTP/controller/service/data路径验证对外行为；尽量不增加零散的内部测试接口。
- 对数据库提交、跨连接读取、回滚、图表数值及错误响应等难以稳定通过界面覆盖的行为，复用现有controller/repository公开入口和HTTP边界作补充集成验证。新增计算适配验证继续用notebook。
- 沿用现有18章教材notebook作为数值回归依据，数据层和controller notebook作为持久化与编排测试先例。网页只做必要交互与端到端测试，不通过组件内部状态或私有方法断言实现细节。
- 正向主链：教材示例或上传 → 预览与口径确认 → 派生数据集 → VaR/谱风险/标准误试算 → 图表与表格 → 手动保存 → 新会话打开记录 → 修改后另存 → 导出与归档。
- 数值正确性使用教材例题、手算值或可独立验证关系作为锚点，并对照已有Python服务结果；不只验证网页和同一实现给出相同输出。图表坐标、阈值线与表格指标相符。
- 验证收益率单位、正负号、模型输入类型、两类置信水平及模型比较的样本对齐；未经确认不发生隐式清洗、换算或删行。
- 验证错误输入、空结果和非有限值的显示，失败/取消任务状态、页面切换后的任务可见性、重复点击不会误写记录，以及试算未保存时不产生正式计算记录。
- 验证真实数据库提交后跨连接读取、派生血缘、原始快照不变、归档后的历史可读性和旧记录兼容；测试仅清理自身生成的记录，不改用户业务样本。
- 验证CSV/JSON导出可读取且与保存内容一致、PNG可用；运行TypeScript检查和前端生产构建，完成关键页面交互检查，18章原有notebook继续通过。

## Out of Scope

- 首版完整接入第2至18章计算页面。
- 多用户、账号权限、公开网络部署、移动端专门设计。
- 在线行情获取、网页逐格编辑、任意拖拽流程和任意Python代码执行。
- 参数法头寸换算、自动隐藏数据清洗或默认补零。
- Word/PDF报告生成、整本教材PDF嵌入、Bootstrap重采样分布图。
- 程序重启后的任务自动续算、分布式任务系统、大规模行情逐行SQL存储重构。
